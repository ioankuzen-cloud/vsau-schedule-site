# Публикация сайта расписания ВГАУ

Готовая публичная версия запускается одним сервером:

- `/students/` - расписание студентов
- `/teachers/` - расписание преподавателей
- `/rooms/` - расписание аудиторий

Локальная проверка:

```powershell
py -3 public_server.py 8080
```

После запуска открыть:

```text
http://127.0.0.1:8080/
```

## Render

Подходит для бесплатного публичного запуска. На бесплатном тарифе сайт может "засыпать" после паузы без посетителей, поэтому первый вход иногда открывается медленнее.

1. Создать репозиторий на GitHub и загрузить в него весь проект.
2. В Render выбрать `New` -> `Blueprint`.
3. Подключить репозиторий с проектом.
4. Render прочитает `render.yaml` и создаст веб-сервис.
5. После сборки сайт будет доступен по адресу вида `https://vsau-schedule.onrender.com`.

## Railway

Подходит, если нужен простой деплой из GitHub или CLI. Если платформа попросит Start Command, указать `python public_server.py`.

1. Создать проект из GitHub-репозитория.
2. Railway сам определит Python-приложение или Dockerfile.
3. Если нужен Start Command: `python public_server.py`.
4. После деплоя открыть публичный домен в настройках проекта.

## VPS

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
PORT=8000 python public_server.py
```

Для постоянной работы на VPS лучше запускать через systemd или Docker.
